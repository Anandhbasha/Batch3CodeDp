1. Add Two Numbers

Task:

Input:

10
20

Output:

2. Find Area of Rectangle

Task:
Create a function `area()` that accepts `length` and `breadth` and returns the area of the rectangle.

Formula:
Area = length × breadth

Input:
10
5


Output:

Area = 50

Concept: Function + arithmetic operators + return value


3. Calculate Simple Interest

Task:
Create a function `simpleInterest()` that accepts **principal, rate, and time** and returns the simple interest.

Formula:
SI = (P × R × T) / 100


Input:
P = 10000
R = 5
T = 2

Output:
Simple Interest = 1000

Concept:Function + multiple parameters + arithmetic operators
